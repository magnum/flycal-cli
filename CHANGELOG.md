# Changelog

## [0.1.0] - 2025-02-26

### Aggiunto

- Comando `flycal login` per autenticazione OAuth con Google
- Comando `flycal logout` per disconnessione
- Comando `flycal calendars` per lista calendari e selezione default (con TTY::Prompt)
- Comando `flycal search` per ricerca eventi con filtri (--from, --to, --calendar, --description)
- Configurazione in ~/.flycal/config.yml
- Supporto per google-apis-calendar_v3
